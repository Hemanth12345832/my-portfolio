## 💡 About
This is a modern, single-page portfolio designed to showcase my skills, projects, and passion for building AI-powered web applications. The website features a dynamic premium design with smooth micro-animations, glassmorphism UI elements, responsive layouts, and spring-physics inspired transitions.

## 🛠️ Tech Stack & Tools
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend/Services:** Firebase, SQL
- **AI Integrations:** Gemini API
- **Tools:** GitHub, Git

## 📂 Features
- **Hero Section:** Dynamic typing text, smooth animations, and direct links to projects and resume downloads.
- **Projects Showcase:** Displays featured work (like AI Resume Builder) with mockups, descriptions, tags, and video demo integrations.
- **Responsiveness:** Fully optimized for seamless viewing across Desktop, Tablet, and Mobile devices.
- **Contact:** Quick access to my email, LinkedIn, and GitHub profile.

## 💻 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Hemanth12345832/my-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd my-portfolio
   ```
3. Open `index.html` in your favorite web browser (or use Live Server in VS Code).
